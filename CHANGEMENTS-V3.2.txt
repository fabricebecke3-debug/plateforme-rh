TERH PAIE - VERSION 3.2 (fiche reorganisee, donnees salarie partout, enregistrement propose)
=========================================================================================

FICHE SALARIE (index.html)
- Formulaire regroupe en 5 sections : Identite ; Contrat et presence ; Remuneration et paie ;
  Classification ; Securite sociale et suivi. Memes champs, memes donnees : aucune perte.

PAIE : UNE SEULE SOURCE DE DONNEES
- Tous les points d'entree (bouton Bulletin detaille, module paie) lisent la meme liste TERH_fichesPaie :
  identifiant, nom, matricule interne (table des matricules), N° CNPS, salaire, horaire, date d'entree,
  lieu, niveau, coefficient, indice, categorie, emploi, convention, etablissement.
- Avant : deux listes differentes ; l'une ne transmettait que le nom et le matricule.

ENREGISTREMENT PROPOSE
- Si le bulletin contient un N° CNPS ou un matricule different de la fiche, un bandeau jaune le signale
  et propose « Enregistrer dans la fiche » : le N° CNPS est mis a jour dans la fiche, le matricule dans la
  table des matricules. Le bouton est desactive pendant l'enregistrement.
- Les matricules importes par le module de lecture des bulletins (DIPE) sont dans la meme table : la paie
  les prend apres actualisation.

LIMITES
- Le matricule n'est pas affiche dans la fiche elle-meme : il se gere dans l'ecran des matricules.
- Teste hors navigateur : syntaxe des scripts, presence des champs. Le rendu et l'enregistrement reel
  (base de donnees) restent a verifier a l'ecran.
